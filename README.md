# estructura_datos_p1373_s2
Este proyecto es una herramienta de consola desarrollada para comparar la eficiencia de dos algoritmos fundamentales de búsqueda: **Búsqueda Secuencial** y **Búsqueda Binaria**. El programa evalúa el rendimiento de ambos métodos aplicando la búsqueda sobre un arreglo de 1,000,000 de números enteros.
